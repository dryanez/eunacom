## 📌 1. FILOSOFÍA PEDAGÓGICA Y ESTRUCTURA DE CONTENIDO

### 🎯 El Problema Anterior vs La Solución Actual
* **El Problema del Modelo Antiguo (10–14 clases comprimidas)**:
  - Se intentaba explicar *Angina Estable + SCASEST + SCACEST + Complicaciones Mecánicas + Fármacos* en 1 solo video de 14 diapositivas.
  - Resultado: Diapositivas sobrecargadas de texto, diagramas microscópicos apretados, información cortada y videos densos y aburridos.
* **La Solución (Modelo Granular de 36 Clases)**:
  - **1 Tema = 1 Masterclass Dedicada** (10 a 20 minutos por video).
  - **1 Diapositiva = 1 Sola Idea Principal** (Estándar *Boards & Beyond*):
    - Máximo 3 a 4 viñetas cortas.
    - Palabras clave destacadas en **negrita roja** o **negrita azul**.
    - Una ilustración médica vectorial, tira de ECG o tabla comparativa dedicada por diapositiva.
    - Cero texto amontonado.

```

│    – Sub-viñeta: Criterio diagnóstico específico           │     [ TABLA COMPARATIVA   │
│                                                            │     [ DEDICADA ]          │
│  • Viñeta de Tratamiento / Conducta Obligatoria:           │                           │
│    – Fármaco de 1ra línea con dosis exacta                 │                           │
│    – Meta terapéutica o alarma de seguridad                │                           │
│                                                            │                           │
├────────────────────────────────────────────────────────────────────────────────────────┤
│  💡 Regla de Oro EUNACOM: Perla clínica de máxima rentabilidad para el examen.         │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

1. **Columna Izquierda (Texto)**:
   - 3 a 5 viñetas concisas.
   - Destacar palabras críticas en negrita de color (`#dc2626` para peligro/alarma, `#0284c7` para fármacos/metas).
2. **Columna Derecha (Visual)**:
   - Una imagen anatómica, tira de ECG con la alteración ampliada, curva de presión/volumen o tabla comparativa.
3. **Pacing / Ritmo**:
   - Cada diapositiva dura entre **25 a 45 segundos de audio**, permitiendo que la clase fluya rápido y mantenga el 100% de la atención.
