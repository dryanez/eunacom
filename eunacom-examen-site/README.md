# Academia Examen EUNACOM · Sitio Web Oficial

Sitio web institucional y plataforma de cursos de preparación médica para el Examen Único Nacional de Conocimientos de Medicina (**EUNACOM** ST Teórico y ECOE Práctico SP) en Chile.

## 🚀 Características
- **Cursos y Precios:**
  - **Curso Teórico EUNACOM:** Modalidades *Online Intensivo* y *Online Regular* ($359.000 CLP / ~390 USD), acceso a Webpay en cuotas y transferencia bancaria Santander.
  - **Curso Práctico ECOE (Próximamente):** Simulaciones clínicas de las 4 áreas troncales (Medicina Interna, Pediatría, Cirugía, Obstetricia & Ginecología) con lista de espera prioritaria.
  - **Masterclass Cardiología de Alto Rendimiento:** Reproductor interactivo y desgloses de casos clínicos de alta frecuencia.
- **Centro de Inteligencia Médica & Guías Clínicas:**
  - Artículos y guías especializadas (Fechas oficiales ASOFAMECH, sueldos médicos en Chile, GES/FONASA, pauta ECOE, errores frecuentes).
- **Herramientas para Médicos Extranjeros:**
  - Matriz interactiva de las 4 vías de revalidación médica (Ley Nº 20.261 y Tratados Bilaterales).
- **Prueba Diagnóstica Gratuita:**
  - Simulacro clínico con feedback y justificación de distractores.

## 🛠️ Stack Tecnológico
- **Framework:** React 19 + Vite 6
- **Estilos:** CSS Variables + Component-level clean design
- **Iconografía:** Lucide React
- **Despliegue:** Vercel / Netlify / Cloudflare Pages

## 📦 Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Ejecutar suite de validación y smoke tests
npm run smoke

# Compilar para producción
npm run build
```
