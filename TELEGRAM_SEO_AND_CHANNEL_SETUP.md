## 🤖 4. Configuración del Bot en Telegram con @BotFather

Para que el bot pueda publicar automáticamente las encuestas y casos clínicos:

1. Abre Telegram y busca a **`@BotFather`** (la cuenta oficial con insignia de verificación azul).
2. Envía el comando:
   ```text
   /newbot
   ```
3. Asigna un nombre al bot, por ejemplo:
   ```text
   Eunacom Quiz Bot
   ```
4. Asigna un username terminado en `bot`, por ejemplo:
   ```text
   eunacom_app_bot
   ```
5. `@BotFather` te entregará tu **Bot Token** (algo como `7123456789:AAFlkJsd89342kljsdf98234-sd`). **Copia este token**.

6. **Agregar el Bot como Administrador a los Canales:**
   - Entra a tu canal (`Preguntas EUNACOM`, etc.).
   - Toca el nombre del canal arriba -> **Editar** (ícono de lápiz o Configuración) -> **Administradores** -> **Añadir Administrador**.
   - Busca el username de tu bot (ej: `@eunacom_app_bot`) y agrégalo.
   - Asegúrate de darle permiso para **Publicar Mensajes** (`Post Messages`).

## ⏰ 7. Métodos de Automatización Diaria

Tienes 3 opciones sencillas y robustas para que funcione 100% en automático todos los días a las 09:00 AM:

### Opción A: GitHub Actions (Recomendada - 100% Gratis, Sin Servidor)
Ya dejamos configurado el flujo en `.github/workflows/telegram_daily_question.yml`.
1. Ve a tu repositorio en GitHub -> **Settings** -> **Secrets and variables** -> **Actions**.
2. Agrega los 2 secretos:
   - `TELEGRAM_BOT_TOKEN`: Tu token de @BotFather.
   - `TELEGRAM_CHANNEL_IDS`: Tus canales (`@preguntas_eunacom,@exameneunacom,@eunacomteorico2026`).
3. ¡Listo! GitHub ejecutará el script todos los días a las 09:00 AM hora de Santiago y guardará el historial de preguntas para no repetirlas jamás.

### Opción B: Ejecutor Local / VPS Continuo (Scheduler Daemon)
Si tienes un servidor VPS o tu computador encendido:
```bash
cd telegram-bot
npm start
```
El proceso quedará en segundo plano esperando la hora exacta configurada (09:00 AM Chile) para publicar.

### Opción C: Vercel Cron / Webhook
Ya creamos el endpoint `/api/telegram-cron`. Puedes configurar un cron job gratuito en [cron-job.org](https://cron-job.org) o Vercel Cron llamando a:
```text
GET https://www.eunacomapp.cl/api/telegram-cron?secret=TU_CRON_SECRET
```
