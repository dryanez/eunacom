# eunacom-examen-site-v1

The original look, kept only for comparison against `../eunacom-examen-site`.
Same content and same sections; what differs is the visual language — Inter,
rounded cards, gradients and coloured accents, rather than the Montserrat /
Open Sans, flat, 3px system taken from the design bundle.

The content corrections apply here too: no personal name, registry number or
alma mater; no ECOE course; reconstrucciones listed as course material.

Run both at once to compare:

    cd eunacom-examen-site    && npm run dev   # http://localhost:5173
    cd eunacom-examen-site-v1 && npm run dev   # http://localhost:5174

Only `eunacom-examen-site` deploys.
