# Agent Guidelines

Issues and specs are tracked in GitHub Issues using the `gh` CLI (`origin`: `dryanez/eunacom`). See `docs/agents/issue-tracker.md`.

### Triage labels

Standard triage label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repository layout (`CONTEXT.md` and `docs/adr/`). See `docs/agents/domain.md`.
